# 比赛合规与证据边界

现场运行 TargetLab 前，必须由人工确认组委会允许执行通用硬件微基准。若不允许，停止测量并使用赛前合法 Profile。禁止读取、探测、计时或推断官方隐藏测试程序，禁止把文件名、路径、源码字节、case ID、期望输出、hash、AST 指纹或测试常量标签输入成本模型。

Profile 只描述 ISA/ABI、目标流水线类别、通用微核测量和统计质量。DecisionTrace 只接收函数/候选稳定名及成本，不接收测试身份。架构测试会扫描公共成本契约，防止未来增加泄漏字段。

证据分级固定如下：

1. BOOM v3 同机配对实测：可进入 R1/R2 正式门禁。
2. QEMU bare-metal/user、动态指令、静态成本：诊断和实现验证。
3. Host smoke、单元测试、Oracle/定向微核：正确性或局部机制证据。

只有赛事 LLVM、相同 ABI/运行时/输入/硬件、至少五次冷启动的配对结果才能支持“超越 LLVM”。R1/R2 未通过各自 GM 置信下界和单例长尾门槛时，只能报告候选状态与真实差距。
